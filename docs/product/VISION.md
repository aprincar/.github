# Aprincar — Vision

## O produto

Aprincar é uma plataforma open-source de aprendizagem através do brincar.

O produto conecta famílias, crianças, educadores e desenvolvedores sem transformar a experiência infantil em um sistema escolar administrativo.

## Para a criança

A Home prioriza:

```text
saudação → personagem → ação → continuar brincando → descobertas → categorias
```

Pouco texto, interação clara e nenhuma pressão artificial.

## Para a família

Parent Mode explica atividade e progresso sem prometer diagnóstico, domínio escolar ou precisão que as evidências não suportam.

## Para desenvolvedores

Um autor externo deve conseguir rapidamente escolher um template, rodar o exemplo, modificar, validar, gerar artifact e compreender o SDK.

## Plataforma

O núcleo deve permanecer pequeno. Funcionalidades que não pertencem ao kernel devem preferencialmente existir como extensões, packages ou adapters.

## Critério de decisão

Uma decisão é consistente com a visão quando melhora autonomia da criança, clareza para a família, extensibilidade, privacidade, local/offline-first, manutenção, segurança, qualidade pedagógica ou developer experience sem violar os demais princípios.
