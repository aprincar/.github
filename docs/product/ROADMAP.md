# Aprincar — Roadmap

## V1.0 — fechamento

Objetivo: transformar o estado funcional atual em uma release reproduzível e documentada.

- sensitive permissions default-deny;
- Registry merge único;
- games-official pinado e sincronizado deterministicamente;
- templates com strict typecheck;
- documentação canônica;
- pacote de marca completo;
- release/version policy;
- GitHub Releases;
- production smoke final.

## V1.1 — qualidade e comunidade

- accessibility automation (axe + keyboard/focus regression);
- documentação de authoring aprofundada;
- link checker;
- artifact budgets;
- dashboards de qualidade não infantis;
- melhorar fluxo Community → Curated;
- ampliar atividades off-screen.

## V1.2 — plataforma extensível

- capability broker para permissões sensíveis com consentimento do responsável;
- version negotiation do SDK;
- sync opcional preservando local-first;
- registry federation com assinatura/publisher identity;
- ferramentas melhores para authoring/debug de Evidence;
- curriculum adapters adicionais sem contaminar Skill Graph.
